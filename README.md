# 📝 AI Text Summarizer

## 📌 Project Overview

AI Text Summarizer is a web-based application that helps users convert long text into short, clear, and meaningful summaries using Artificial Intelligence.

The application provides a simple and user-friendly interface where users can enter lengthy text and generate a concise summary, making information easier to read and understand.

## 🎯 Objectives

- To summarize long text into shorter content.
- To save time when reading lengthy information.
- To make important information easier to understand.
- To provide a simple and interactive web application.
- To explore AI-powered Natural Language Processing (NLP).

## ✨ Features

- 📝 Text input for lengthy content.
- 🤖 AI-powered text summarization.
- 📄 Short and meaningful summaries.
- ⚡ Simple and user-friendly interface.
- 🌐 Web-based application built with Streamlit.

## 🛠️ Technologies Used

- **Python** – Core programming language.
- **Streamlit** – Web application interface.
- **Hugging Face Transformers** – AI model integration for text summarization.

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/keerthikamani827-jpg/Text_Summerization.git
```

### Step 2: Open the Project Folder

```bash
cd Text_Summerization
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run the Application

```bash
python -m streamlit run app.py
```

### Step 5: Open the Application

Streamlit will provide a local URL, usually:

```text
http://localhost:8501
```

Open the URL in your browser to use the application.

## 🚀 How to Use

1. Open the AI Text Summarizer application.
2. Enter or paste the text you want to summarize.
3. Click the summarization button.
4. View the generated summary.
5. Read the shorter version of the original text.
